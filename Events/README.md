# Using these resources

This section of the repository contains links to code examples that have been used in specific events. Please note that the notebooks themselves are still filed under the relevant service sections of the repository.

Each event contains an index notebook that provides links to the resources for a specific training intervention. The index notebooks are all stored in the following form:

EVENT_YEAR_index.ipynb

For example, for the training material presented during the 2026 EUMETSAT conference "From Data to Insights" session, please see:

EUMETSAT_CONFERENCE_2026.ipynb

Any corresponding presentations, given as context tot he notebooks are included with the same naming structure, for example:

EUMETSAT_CONFERENCE_2026.pdf
